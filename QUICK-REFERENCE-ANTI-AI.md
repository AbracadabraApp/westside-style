**Full Algorithm:** See `ANTI-AI-SLOP-ALGORITHM.md`

---

## 2-MINUTE SPOT CHECK

```
1. Search "incredibly" → should be 0
2. Search "seamlessly" → should be 0
3. Search "transformation" → should be 0
4. Check terminology:
   - "hand-sewn wefts" (not variations)
   - "keratin bonds" or "k-tips"
   - "Jenn" (not Jennifer)
5. Read one paragraph aloud → sounds like talking?
```

**If all pass → page is clean**
**If any fail → use full algorithm**

---

## BANNED WORD LIST (Never Use)

```
delve               unlock              incredibly
leverage            harness             gold standard
tapestry            seamlessly          unparalleled
journey (fig)       virtually           transform (marketing)
```

---

## REQUIRED REPLACEMENTS

```
"when it comes to" → delete
"incredibly flat" → "very flat" or "about 2mm thick"
"virtually invisible" → "nearly invisible" or measurement
"With proper care" → specify what care means
"TRANSFORMATION" → "RESULTS"
"discover how X can transform" → "see if X makes sense"
```

---

## SITE TERMINOLOGY (Must Be Exact)

```
✅ hand-sewn wefts
❌ hand tied wefts, hand-sewn extensions, handtied

✅ keratin bonds OR k-tips
❌ keratin tip extensions, keratin bond extensions

✅ Jenn
❌ Jennifer (except formal About page bio)

✅ tape-ins
❌ tape-in extensions (in casual copy)
```

---

## ADD TO EVERY LANDING PAGE

```
□ 3+ specific numbers (cost, measurement, timeframe)
□ 1-2 honest tradeoffs
□ 1 parenthetical aside: "(This is why...)"
□ Vary sentence length (short + long)
□ Read aloud test passes
```
