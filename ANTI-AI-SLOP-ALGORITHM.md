# ANTI-AI SLOP REWRITE ALGORITHM
## Westside Style Hair Extensions - Content Standards

**Purpose:** Transform AI-generated or overly polished marketing copy into human-sounding, credible content while maintaining professional structure and conversion intent.

**Last Updated:** January 16, 2025

---

## SITE-SPECIFIC STYLE RULES

**Terminology (MUST be consistent):**
- ✅ "hand-sewn wefts" (never "hand tied wefts", "hand-sewn extensions", "handtied")
- ✅ "keratin bonds" or "k-tips" (never "keratin tip extensions", "keratin bond extensions")
- ✅ "Jenn" (never "Jennifer", "Jennifer Arges" except in formal bios)
- ✅ "tape-ins" (not "tape-in extensions" in casual copy)

**Voice:**
- Consultative, not pushy
- Specific over vague
- Honest about tradeoffs
- Like explaining to a friend who asked

## PRE-FLIGHT DIAGNOSTIC

Run these counts before starting:

```
AUTOMATED CHECKS:
□ Em-dash count: Should be ≤2 per page (AI uses 20+)
□ Robot words: Search for these and count total
  - delve, leverage, tapestry, landscape (figurative), journey (figurative)
  - unlock, harness, seamlessly, virtually, incredibly
  - gold standard, unparalleled, robust, pivotal, crucial
  - elevate, empower, testament, synergy, paradigm

□ Transformation language: Count instances
  - "transform your", "discover how", "ready for your transformation"

□ Sentence length variance check:
  - Count sentences 15-20 words: If >80%, needs burstiness
  - Check for ≥1 sentence ≤6 words
  - Check for ≥1 sentence 25+ words

□ Specificity check:
  - Count numbers/measurements: Should be 3+ per section
  - Count dollar amounts: Should be visible on pricing pages
  - Count timeframes: Should be specific ("6-8 weeks", not "regularly")
```

**If any check fails → Proceed to algorithm**

## THE ALGORITHM (12 STEPS)

### **STEP 1: BANNED WORD PURGE (Automated)**

**Tier 1 - NEVER USE (Auto-replace):**
```
delve → delete or "look at"
leverage → "use"
tapestry → delete
landscape (figurative) → delete ("the extension landscape" → "extension options")
journey (figurative) → delete ("your hair journey" → "your hair")
unlock → delete ("unlock your potential" → delete entirely)
harness → "use"
seamlessly → "naturally" OR delete
  - "blend seamlessly" → "blend naturally"
  - "lays seamlessly" → "sits flat"
virtually → "nearly" OR specific measurement
  - "virtually invisible" → "nearly invisible" or "about 3mm"
incredibly → DELETE or "very"
  - "incredibly flat" → "very flat" or "flat"
gold standard → DELETE or "premium"
unparalleled → DELETE or "great"
  - "unparalleled flexibility" → "great flexibility"
robust → "strong" or "durable"
pivotal → "important"
crucial → "important"
elevate → "improve"
empower → DELETE
testament → DELETE
synergy → DELETE
paradigm → DELETE
```

**Tier 2 - MAX ONCE PER PAGE:**
```
comprehensive → "complete" or delete
innovative → delete or "new"
transformative → delete
cutting-edge → "new" or delete
game-changing → delete
significant → "important" or specific impact
```

**SITE-SPECIFIC REPLACEMENTS:**
```
"hand tied" → "hand-sewn wefts"
"hand-tied extensions" → "hand-sewn wefts"
"keratin tip extensions" → "keratin bonds" or "k-tips"
"keratin bond extensions" → "keratin bonds"
"Jennifer" → "Jenn" (except in About page formal bio)
```

---

### **STEP 2: BANNED PHRASE KILL**

**AI Meta-commentary (Delete entirely):**
```
"It's important to note that" → delete, state directly
"When it comes to" → delete, rephrase
"At the end of the day" → delete
"Here's the thing:" → delete
"The key is" → delete, state directly
"Let's explore" → start content directly
"Let's dive into" → start content directly
"Let's break down" → start content directly
```

**Filler Phrases (Replace with specifics):**
```
"With proper care and maintenance" → specify what care means
  - "Use sulfate-free shampoo, brush twice daily"
  - "Come back every 6-8 weeks for move-ups"

"typically last" → specific timeframe + cost
  - "typically last 6-8 weeks" → "need move-ups every 6-8 weeks (about $200-300)"

"small sections" → actual number
  - "small sections" → "10-15 strands per bond"

"high-quality" → delete (implied) or specify
  - "high-quality wefts" → "wefts"
  - OR "Bellami wefts" (if true)
```

**Transformation Language (Reframe consultatively):**
```
"READY FOR YOUR TRANSFORMATION?" → "WANT TO SEE IF THEY'RE RIGHT FOR YOU?"
"discover how [X] can transform your hair" → "see if [X] makes sense for you"
"transform your look" → delete or specific outcome
"Book your free consultation and discover..." → "Free consultation to look at your hair and see if..."
```

---

### **STEP 3: STRUCTURAL PATTERN BREAK**

**Kill these AI structures:**

**Fractal Summaries:**
```
❌ "In this section, we'll explore..."
❌ "As we've seen above..."
❌ "To summarize..."
→ Just start the content
```

**Pep-Talk Endings:**
```
❌ "As we move forward, embracing X will be key to..."
❌ "The future of your hair awaits..."
→ End on last concrete point
```

**Prompt Echo:**
```
❌ "This page will explain..."
❌ "We're here to help you understand..."
→ Delete, start with content
```

**Both-Sidesing:**
```
❌ "While X has benefits, it also has considerations to keep in mind."
→ "X lasts 4-6 months. You'll pay $200-300 every other month for move-ups."
```

---

### **STEP 4: SUPERLATIVE DOWNGRADE**

**Headers/Titles:**
```
MOST NATURAL MOVEMENT → NATURAL MOVEMENT
MAXIMUM VERSATILITY → VERY VERSATILE
PERFECT FOR FINE HAIR → BEST FOR FINE HAIR
THE ULTIMATE SOLUTION → A GOOD OPTION (or just describe it)
```

**Body Copy:**
```
"the most natural look" → "a natural look"
"the best option available" → "a good option"
"perfect for all hair types" → "works well for most hair types"
"the only method that" → "one method that"
```

**Rule:** If >50% of benefit headers use MOST/MAXIMUM/PERFECT, reduce by half.

---

### **STEP 5: AUDIO TEST (Read Aloud)**

**Read each sentence out loud. Mark unnatural pauses.**

**Bad Rhythm (AI):**
```
❌ "This method creates an incredibly flat, lightweight application that's virtually undetectable and provides seamless integration with your natural hair."
→ Too long, too many clauses, robotic adjectives
```

**Good Rhythm (Human):**
```
✅ "The beads are about 2mm thick. You won't see bumps when you wear your hair up or in a tight ponytail."
→ Short sentences, concrete, conversational
```

**Fixes:**
- Break compound sentences with 3+ clauses
- Use contractions (you'll, won't, can't, they're)
- Start 1-2 sentences with "And" or "But"
- Add parenthetical aside: "(This is why I book 3 months out)"
- Vary sentence rhythm - not all medium-length

---

### **STEP 6: BURSTINESS INJECTION**

**Per section (200-300 words), require:**

```
□ 1 sentence ≤6 words
  - "They last 4-6 months."
  - "You'll need move-ups."

□ 1 sentence 25+ words (with natural flow)
  - "You'll need move-ups every 6-8 weeks for tightening and repositioning, which runs about $200-300 depending on how much your hair grew."

□ 1 single-sentence paragraph

□ Avoid >8 consecutive sentences of 15-20 words
```

**Test:**
- Count words per sentence
- If 80%+ are 15-20 words → add burstiness
- If all paragraphs are 3-4 sentences → break pattern

---

### **STEP 7: CREDIBILITY INJECTION (Add Honest Tradeoffs)**

**Every benefit needs context, comparison, or limitation.**

**Before (Pure Benefit):**
```
❌ "Weft installation is quicker than individual bonds, with beautiful results in less time."
```

**After (Benefit + Real Comparison):**
```
✅ "90-120 minutes vs 3-5 hours for keratin bonds. Good if you can't sit for long appointments."
```

**Patterns:**
- Benefit + comparison with numbers
- Benefit + who it's NOT for
- Benefit + honest limitation
- Benefit + what to expect initially

**Examples:**
```
✅ "They sit very flat — about 2mm. First few nights sleeping on them feels tight for most people."
✅ "Lasts 4-6 months before move-up (vs 6-8 weeks for tape-ins)."
✅ "Not great if you have very thin hair or bald spots — not enough to attach to."
```

**Test:** If benefit section is 100% positive with no caveats → add 1-2 honest tradeoffs.

---

### **STEP 8: NUMBER INJECTION (Replace Adjectives with Data)**

**Pattern: Descriptive word → Measurement**

```
"incredibly flat" → "about 2mm thick"
"virtually invisible" → "about 3mm bonds"
"lightweight" → "weighs about X grams" OR "2mm thick"
"long-lasting" → "4-6 months"
"affordable" → "$1,200 starting" OR "$200-300/month"
"quick application" → "90 minutes"
"small sections" → "10-15 strands per bond"
"regular maintenance" → "every 6-8 weeks"
"multiple times" → "3-4 times" or "9-12 months total"
```

**Add where missing:**
- Installation time in minutes/hours
- Cost in dollars (both upfront and monthly breakdown)
- Dimensions in mm/cm
- Timeframes in weeks/months
- Quantities (strands per bond, rows needed, etc.)
- Reuse cycles (how many times)

**Test:** Count specific numbers in body copy (excluding CTA prices). Aim for 3+ per section.

---

### **STEP 9: HUMAN MARKER INJECTION**

**Add these elements:**

**Named Brands/Products (when true):**
```
✅ "Use sulfate-free shampoo (like Olaplex or Pureology)"
✅ "I use Bellami hand-sewn wefts"
✅ "Avoid oil-based products like Moroccan Oil near the bonds"
```

**Specific Tools:**
```
✅ "Use a loop brush designed for extensions"
✅ "keratin heating tool at 180°F"
✅ "micro-beads (about 2-3mm)"
```

**Minor Formatting Variations:**
```
□ Drop 1 Oxford comma in casual section (not in lists)
  - "extensions for length, volume and thickness" (casual)
  - "keratin bonds, hand-sewn wefts, and tape-ins" (formal list - keep comma)
```

**Irrelevant-But-True Details:**
```
✅ "(I usually book Tuesdays and Thursdays)"
✅ "(Most people adjust by day 4, some take a week)"
✅ "(This is why I don't do same-day installs)"
```

**Unresolved Edges (don't fix everything):**
```
✅ "Some people never get used to the feeling of beads"
✅ "Fine hair might not have enough density to hide the rows"
✅ "First 3 nights sleeping on them feels weird"
```

---

### **STEP 10: SOUL DETECTOR TEST**

**Find the 3 most artificial sentences and rewrite as if talking to a friend.**

**How to identify artificial sentences:**
- Uses 3+ AI words (incredibly, virtually, seamlessly)
- No concrete details (all adjectives, no numbers)
- Too perfect/polished
- Sounds like a brochure
- You'd never say it out loud

**Examples:**

**Sentence 1 (Artificial):**
```
❌ "This method creates an incredibly flat, lightweight application that's virtually undetectable and provides seamless integration with your natural hair."
```

**Rewrite (To a Friend):**
```
✅ "The beads are about 2mm thick, so they sit really flat and you can't see them when your hair is down."
```

**Sentence 2 (Artificial):**
```
❌ "With proper maintenance and care, hand-tied extensions can be reused multiple times, making them a cost-effective investment."
```

**Rewrite (To a Friend):**
```
✅ "The wefts can be reused 3-4 times before you need new hair — typically 9-12 months total."
```

**Sentence 3 (Artificial):**
```
❌ "Weft installation is significantly quicker than individual bond application, allowing you to achieve beautiful results in less time."
```

**Rewrite (To a Friend):**
```
✅ "90-120 minutes vs 3-5 hours for keratin bonds. Good if you can't sit that long."
```

---

### **STEP 11: IMPERFECTIONS INJECTOR**

**Add micro-imperfections that show lived experience.**

**Strong Opinion (1 per page):**
```
✅ "I don't recommend tape-ins if you swim 5+ days a week — they'll slip out."
✅ "Keratin bonds aren't great for very fine hair. You need some thickness to hide them."
```

**Hesitation/Qualification:**
```
✅ "Most people adjust by day 4, though some take a week."
✅ "Works well for fine to medium hair. If you have very thick hair, you might need more rows."
```

**Incomplete Sentence (where natural):**
```
✅ "And you're not coming back every 6 weeks."
✅ "But the install does take longer."
```

**Parenthetical Aside (insider info):**
```
✅ "(This is why I book 3 months out)"
✅ "(I usually do 4 rows for fine hair, 6 for medium)"
```

**Minor Contradiction/Complexity:**
```
✅ "They're called 'hand-sewn' but I use a special beading tool for the micro-beads."
✅ "Most people sleep fine after day 3. Some feel it for a week."
```

**Rule:** Do NOT correct these afterward. Leave them raw and real.

---

### **STEP 12: FINAL VALIDATION TESTS**

**A. The Friend Test**
```
Read the entire section as if explaining to a friend who asked:
"What are hand-sewn wefts?"

Would you actually say this out loud?
- If NO → too formal, too polished, or too vague
- If YES → passes
```

**B. The Credibility Test**
```
Read as someone who distrusts polished marketing.

Mark sentences that feel:
- Overly constructed
- Too precise
- Too balanced
- Too perfect

Rewrite those to be slightly messier but more real.
```

**C. The Pattern Test**
```
Check for repeated patterns:
- Same sentence length 5+ times in a row
- Same paragraph structure throughout
- Every benefit has same format
- No variation in rhythm

Break at least 2 patterns per page.
```

**D. The Em-Dash Count**
```
Count em-dashes (—) in the page.
- AI: 15-25 per page
- Human: 1-3 per page

If >5, reduce to 2-3 max.
```

## EXAMPLE: BEFORE/AFTER

### **BEFORE (AI Slop)**

```
INCREDIBLY FLAT AND COMFORTABLE

Hand tied extensions use high-quality wefts that are hand-sewn onto
small, micro-beaded rows installed in your natural hair. This innovative
method creates an incredibly flat, lightweight application that's
virtually undetectable and provides seamless integration with your
natural hair.

With proper maintenance, hand tied extensions can last for extended
periods, making them a cost-effective solution. The flattest weft method
available, they lay seamlessly against your head with no visible bumps
or bulk.

Ready for your transformation? Book your free consultation and discover
how hand tied extensions can transform your hair and elevate your look.
```

**Issues:**
- "incredibly" (2×), "virtually", "seamlessly" (2×)
- "high-quality" filler
- "innovative", "cost-effective" vague marketing
- No specific numbers
- Transformation language
- All sentences 15-20 words
- No tradeoffs
- Too perfect/polished

---

### **AFTER (Human Voice)**

```
VERY FLAT

Hand-sewn wefts are sewn onto micro-beaded rows in your natural hair.
The beads are about 2mm thick, so they sit very flat and are hard to
see or feel.

You'll need move-ups every 6-8 weeks (about $200-300 for tightening
and repositioning). The wefts themselves can be reused 3-4 times before
you need new hair — typically 9-12 months total. (This is why I recommend
them for people who want to commit for at least a year.)

First few nights sleeping on them feels tight for most people. But by
day 4, you won't notice them.

Want to see if they're right for you? Free consultation to look at
your hair and see if hand-sewn wefts make sense.
```

**Improvements:**
- ✅ Robot words removed
- ✅ Site terminology: "hand-sewn wefts"
- ✅ Specific numbers: 2mm, $200-300, 6-8 weeks, 3-4 times, 9-12 months
- ✅ Honest tradeoff: first few nights uncomfortable
- ✅ Parenthetical aside with insider info
- ✅ Sentence variety: "First few nights..." (5 words), long sentence with cost breakdown
- ✅ Starts with "But"
- ✅ Consultative CTA
- ✅ Sounds like a human explaining to a friend

## USAGE INSTRUCTIONS

### **For New Pages:**
1. Run Pre-Flight Diagnostic
2. Apply Steps 1-12 in order
3. Run Comprehensive Checklist
4. If any Tier 1 items fail → fix and retest
5. If Tier 2-3 items fail → judge if acceptable for page type

### **For Existing Pages:**
1. Read page aloud
2. If it sounds robotic → run Pre-Flight Diagnostic
3. Fix only what fails Tier 1 (critical items)
4. For landing pages: fix Tier 2 items
5. For FAQ pages: may skip Tier 3 if already conversational
